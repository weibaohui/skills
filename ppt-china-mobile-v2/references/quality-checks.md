# 固定模板与高密度内容检查

每页交付前渲染最终文件。整页检查模板一致性，放大检查密集文字、线条和表格；修复后重新导出与渲染。

## 模板

- 确认使用内置新模板及对应源页：cover=1、contents/chapter=2、body=3、closing=4。chapter是目录派生。
- 画布、母版与布局保留；Logo只有一份，比例和可见位置与原模板相同。
- 首尾页使用底部蓝绿波浪；目录保留原生编号圆、圆角横条、阴影和左侧目录图案；正文保留白底与Logo。
- 不混入旧点阵背景、旧CONTENTS目录、顶部细线、橙色导航、旧页码。源模板本来就包含的阴影和渐变需要保留。
- 标题、署名、日期、目录和结束语均已替换；源“XXX”“XXX部门”“2026年1月”不能残留在实际页面中。母版编辑提示、日期字段与‹#›不能自动实例化为业务文案。
- Logo图片框负y来自透明留白，是模板原始映射；核对可见标志而非仅靠原始框越界判断。不能以此豁免新内容的越界。
- 总页数与用户约定一致。章页的目录名称、顺序、高亮与后续内容一致。非四项目录须检查新增/删除的整组对象与间距。

## 正文

| 检查项 | 要求 |
|---|---|
| 固定页眉 | 原标题位置/蓝色/24pt层级，标题不碰Logo |
| 内容边界 | 内容位于规划安全区，模块标题、图例、连接线无外溢 |
| 内容完整 | 事实、条件、单位、行列与关系保留，无截断尾行 |
| 密度 | 按当前Skill的高密度目标组织；允许极小字，不能以常规字号下限判错 |
| 图文 | 架构、流程、拓扑表达真实关系；保留必要说明，避免仅用文字填满全部分区 |
| 文字 | 放大可读，术语不拆成单字列，中英文与数字换行合理 |
| 连线 | 指向正确对象、不穿字、不被白底遮住，反馈与主流程可区分 |
| 表格 | 原生表格，列宽行高和真实单元格边距匹配，完整显示末行 |
| 编辑性 | 所需文字、图表、节点和连线可独立编辑；Logo、背景、原始截图及用户接受的静态资产可用图片，不能把需编辑的正文或大型架构整体栅格化 |
| 字体 | 新增文字统一微软雅黑；保留固定源样式，避免整套模板盲目改字族 |

## 工具与交付

`template_page.py`生成的是单页模板种子，不是已完成正文；导入编辑后还要检查。Artifact导入导出可能改变组合、阴影或字体，必须对照原始模板渲染。若损坏固定元素，应修复对应对象或使用保留原始OOXML的局部编辑，不能换回旧版壳层。

检查PPTX关系目标、页数、画布、文字/图形/表格对象与可见页面。无关母版占位文字不作为当前页正文统计。不以文件中存在少量可编辑文字证明大型图形可编辑。

每页交付前保留一轮“去AI味”“更贴近真实人类表述”的自检，自主判断表达；业务事实区分现状、拟建、示例及待确认。按SKILL.md逐页交付，预览默认内部使用，不增加逐页确认。不要宣称在未打开的软件中检查过。
