# 固定模板与正文风格

## 唯一默认模板

2026-11-05 用户提供的《中国移动内部汇报PPT模板.pptx》是当前新作的默认固定模板，内置于 `assets/internal-report-template.pptx`。模板原件保持不变，SHA-256 及源页映射见 `assets/template-manifest.json`。无需再访问原 Downloads 路径。

模板实际有4页：封面、四项目录、空白正文、结束页。画布为12192000×6858000 EMU，即1280×720 CSS px、13⅓×7.5英寸。原始母版、布局、图片和图形组合应随源页复制保留。优先在源页副本上填内容；不要根据文字描述重新猜测整个模板。

## 固定与可变的边界

| 固定项 | 执行要求 |
|---|---|
| 画布、母版、布局 | 保留模板尺寸和源页对应关系 |
| Logo | 保留原布局中的Logo及原始位置、比例和透明留白；不要重复添加 |
| 首尾背景 | 使用模板底部蓝绿波浪原图，保留原映射；不使用旧版角部点阵 |
| 封面标题、署名与日期 | 在原文本对象中替换，保留坐标、对齐、颜色与字体层级 |
| 目录 | 保留左侧“目录”和圆形箭头、右侧四条白色圆角带、蓝色编号圆与阴影 |
| 正文标题 | 复用layout4的标题占位符，微软雅黑24pt、粗体、#0070C0 |
| 结束语 | 替换第4页中央文本对象，默认沿用60pt蓝色粗体和原文本框 |

可变项为当前任务的标题、署名、日期、目录条目、当前章、正文内容，以及正文安全区域内的分区、架构、拓扑、流程、表格与说明。固定模板不等于所有正文都使用同一套卡片。模板没有给出正文分栏，正文分区由内容决定；高密度和小字号要求继续生效。

默认不额外增加旧版顶部细线、橙色章节导航、页码、目录英文CONTENTS、左下弧线或底部说明栏。新模板渲染中没有这些可见元素。需要页码或来源说明时在正文安全区内安排，并记录为本次任务扩展。

## 正文几何与配色

源layout4标题框实测为 x=17.34、y=12.80、w=1078.19、h=43.52 px，文字有原始内边距。使用原占位符，长标题应核对与右上Logo的可见区域是否相交；优先简化标题或合理分行后局部调整，不能移走Logo。

新增正文推荐安全区为 x=24、y=90、w=1232、h=606 px。这是基于模板页眉和页面边界的内容编排约定，不是源文件自带的正文占位符。导语、模块标签和图例也属于此区域。不要在空白正文上铺白色整页图片覆盖模板。

标题与核心强调沿用#0070C0；正文以黑色为主；内部图形可用浅蓝、淡绿和少量橙色表达层级、状态或反馈。原目录编号使用渐变、光晕和阴影，应保留原生组合而非改画成普通圆圈。正文不必沿用目录的阴影或圆角卡片。

模板封面标题40pt、组织日期20pt，结束语60pt；正文标题24pt。这些是源对象属性。目录存在多级分组缩放，逻辑字号不等于显示字号，使用原组合直接替换最可靠。正文与图内细节的字号由两个Skill各自密度规则决定，不套用上述首尾页字号。

新增文字统一微软雅黑的Latin/EA/CS槽；固定模板文字优先保留其原样式。不要对整个模板盲目运行全局字体替换：母版含有未启用的字体和示例字段，其存在不代表可见页面用了这些内容。修改后检查实际可见文字的字体与换行。

## 旧参考的地位

旧规划稿和截图仅提供正文高密度组织方法：多层架构、不等分模块、嵌套图文和矩阵。其Logo位置、封面、目录、背景、导航、页码和页眉已被当前模板替代，不再作为默认样式选择。
